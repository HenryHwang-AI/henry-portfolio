Bot 直聘 Bot Zhipin

这是我做的一个中文 Grok Bot 模板货架。Grok Bot 的模板在 x.ai 上。想来按岗位挑一个助手的人，还是得自己读英文市场页，并猜导入之后会打开哪些权限、花掉多少额度。Bot 直聘把这些模板收成中文说明，导入前先把准备事项写在卡片上。

货架怎么用

首页按岗位浏览 Bot。卡片上能看到额度高低，以及要不要连账号、会不会自己跑。点「导入」会在新标签打开对应的 x.ai 模板页，在那里加入 Grok Bot。模板本身仍归原作者，能不能跑通以 x.ai 那一页为准。

除了全部列表，还有本周主推、按主题收的合集，以及把几个 Bot 编在一起的小队。小队页写明分工，也写明整套配合还没有在 Grok Bot 里实测。这里不把小队写成已经跑通的协作结果。

旁边的两栏，和投稿

同一站点还有 Prompt 和 Skills。Prompt 带原文；Skills 给 Claude Code、Codex 这类助手提供安装说明。另外可以装一个叫 bot-zhipin 的 skill，让助手用自然语言在这个目录里找。

做了 Bot 的人可以打开投稿页：复制提示词，生成投稿包，再用 GitHub 登录提交。站点写的是审核通过后挂上货架。我没有在这篇里把投稿从登录走到上架整段跑完。

打开 Bot 直聘

This is a Chinese shelf of Grok Bot templates that I made. The templates themselves live on x.ai. Someone who wants an assistant shaped for a job still has to read the English marketplace and guess which permissions and how much quota an import will turn on. Bot Zhipin puts those templates into Chinese notes, and writes the prep on the card before import.

How the shelf works

The home page browses bots by role. A card shows whether quota use is low, medium, or high, and whether the bot needs a connected account or can run on its own. Import opens the matching x.ai template page in a new tab, where it is added to Grok Bot. The template still belongs to its author. Whether it actually runs is decided on that x.ai page.

Besides the full list there are weekly picks, themed collections, and squads that group several bots. A squad page states the split of work, and it also states that the full set has not been tested together inside Grok Bot. This page does not treat a squad as a collaboration that has already been proven.

The other two sections, and submissions

The same site also lists prompts and skills. Prompts include the original text. Skills give install notes for assistants such as Claude Code and Codex. A skill named bot-zhipin can be installed so an assistant can search this catalog in natural language.

Someone who has made a bot can open the submit page: copy a prompt, generate a submission pack, then sign in with GitHub to send it. The site says a listing goes up after review. I have not run that path from sign-in through to a live listing for this write-up.
