多 Agent 投放作战室：角色怎么拆、怎么协作 Ad war room: splitting roles so agents actually collaborate

一个人盯投放，很容易陷入「看报表 → 猜原因 → 改预算」的单线程。我做多 Agent 投放作战室时，故意把这条线拆成几条并行的角色，而不是塞进一个万能提示词。舞台上人多没用，接口清晰才有用。

为什么要拆

投放里至少有三类矛盾：目标（花多少换多少）、诊断（哪条计划在漏）、动作（下一步改什么）。混在一个 Agent 里，它会平均化——话好听，但不敢下狠手，也不敢承认不确定。拆开之后，每个角色只对自己的输出负责，协调层再合并冲突，而不是让模型在内心偷偷投票。

我还发现：角色边界一旦写成契约（输入字段、禁止事项、成功标准），后续改提示词就不再是玄学。作战室 Demo 的价值，正是把这些契约摊在台面上。

怎么协作

我用三层：协调 Bot拆任务、定回合；中间是场景角色——目标官、诊断官、动作官；底下工具层优先打广告平台 API，GUI 只在没接口时兜底。一回合里：先对齐 KPI，再读指标异常，最后给出可执行的下一步，而不是再写一篇「建议关注」。

回合制很重要。没有回合，多 Agent 会变成同时刷屏；有了回合，你才能复盘「哪一步把结论带偏了」，也才能接到评测台上做回归。

我学到什么

多 Agent 的价值不在「人多」，而在接口清晰：谁说话、谁有最终拍板权、失败时回滚到哪一步。作战室 Demo 就是把这套回合感可视化——你能看见角色在交班，而不是一个黑盒吐结论。下一篇我会写评测台：没有分数，这套戏就只是好看。

One person watching ads ops defaults to a single thread: read the board, guess, tweak budget. When I built the multi-agent ad war room, I refused the “one mega prompt” path and split the work into parallel roles. Headcount on stage is irrelevant; clear contracts are not.

Why split

Ads work has at least three tensions: goals (spend vs return), diagnosis (which plan is leaking), and action (what to change next). One agent averages them—polite, vague, unwilling to commit. Separate roles own separate outputs; a coordinator resolves conflicts instead of letting the model hold a private vote.

Once role boundaries are written as contracts (inputs, forbidden moves, success criteria), prompt edits stop being mysticism. The war-room demo exists to put those contracts on the table.

How they collaborate

Three layers: a coordinator decomposes turns; scene roles for goals, diagnosis, and actions; a tools layer that prefers platform APIs and only falls back to GUI. One turn: lock KPIs, flag metric anomalies, then emit an executable next step—not another “please monitor” essay.

Turns matter. Without them, multi-agent work becomes simultaneous spam; with them, you can replay which step derailed the conclusion and wire the same path into the eval lab.

What I learned

Multi-agent value is not headcount; it is clear contracts—who speaks, who decides, where you roll back on failure. The demo makes the handoff visible instead of hiding it in a black box. Next: the eval lab—without scores, this is just theater.
