回答准确率。口径是人工标注，评测体系迭代至 V4。不是自动评分。

Answer accuracy. The basis is human labeling, and the evaluation system had reached V4. It is not an automatic score.

一线要面对 1000+ 产品和上千页说明书，还有合规要求。新人上手要 5–6 个月。公司已有大模型底座。这个项目是上级立项之后，由执行负责人往下推：知识图谱和 RAG 双模式的客服助理。

先把知识做成可治理的系统

知识库分成四域：产品、话术、流程、合规，10000+ 条目，并建立「知识 Owner + 有效期」。切片和向量化策略与算法一起定。Prompt 有模板库和版本管理。评测是 6 维人工评测，加 800 条离线样本。六维的具体名称，简历没有列。Prompt 变更前做全量回归。

三个和准确率有关的决定

先立四域，以及 Owner 和有效期。知识是要治理的产品，不是一次导入的语料。

切片和向量化与算法共定。简历所载 Top-3 命中率 68% → 86%。

评测做成变更前的闸门。6 维人工评测和 800 条离线样本，变更前全量回归。维度名称不补。

四版，只写主题

简历写了四版，没有月份，也没有各版的准确率，所以这里不排时间窗：V1 是 MVP；V2 是功能稳定；V3 是业务反馈和数据漏斗双轨；V4 是模型微调。89% 对应「评测体系迭代至 V4」，中间值没有。

结果

回答准确率 62% → 89%。Top-3 命中率 68% → 86%。日均节省人工 200 次。30 天主动留存率 90%+。检索资料时间降低 95%，另记提效 80%+。两则并陈，口径关系未载。

方法上留下四域结构、Owner 与有效期、Prompt 版本管理和回归。简历没有写全公司人数或后续推广范围。

Front-line staff faced 1,000+ products, thousands of pages of manuals, and compliance requirements. A new hire needed 5–6 months to get up to speed. The company already had a large-model base. After a sponsor chartered the work, the execution lead pushed an assistant driven by both a knowledge graph and RAG.

Make the knowledge governable first

The knowledge base has four domains: product, scripts, process, and compliance, 10,000+ entries, with an owner and an expiry on the knowledge. Chunking and embedding were set with the algorithm team. Prompts live in a template library with versions. Evaluation is a 6-dimension human review plus 800 offline samples. The resume does not name the six dimensions. A prompt change requires a full regression first.

Three decisions tied to accuracy

Set the four domains, the owner, and the expiry first. Knowledge is a product to govern, not a one-time corpus import.

Set chunking and embedding with the algorithm team. Resume-reported Top-3 hit rate: 68% → 86%.

Make evaluation the gate before a change. Six-dimension human review and 800 offline samples, with a full regression before a prompt change. The dimension names are not filled in.

Four versions, themes only

The resume names four versions and gives neither months nor a per-version accuracy, so there is no calendar here. V1 is the MVP. V2 is functional stability. V3 is business feedback plus a data-funnel track. V4 is model fine-tuning. The 89% figure is tied to “evaluation iterated through V4.” Intermediate values are not in the resume.

Outcomes

Answer accuracy 62% → 89%. Top-3 hit rate 68% → 86%. About 200 manual lookups saved per day. 30-day voluntary retention 90%+. Time spent searching materials down 95%, with a separate note of efficiency up 80%+. Both lines stay; how they relate is not defined.

The method left behind is the four-domain structure, owner plus expiry, and prompt versioning with regression. The resume does not give a company-wide headcount or a later rollout scope.
