Agent 分层 Agent layering

我把工作拆成三层：上面协调，中间按场景干活，底下优先走 API，GUI 只做兜底。这样评测台、投放室和 RAG 顾问可以共用同一套工具，又各自独立迭代。

three layers: a coordinator on top, scene bots in the middle, and a tools layer that prefers APIs with GUI as fallback. eval lab, war room, and citation RAG share tools but ship on their own cadence.

  1. 管理 / 协调 Bot — 拆任务、路由、汇总结果 manager / coordinator — decompose, route, summarize
  2. 场景 Bot — 广告评测 · 投放作战 · 行业 RAG scene bots — ad eval · media buying · industry RAG
  3. 工具层 — API 优先，GUI 兜底 tools — API first, GUI as fallback
